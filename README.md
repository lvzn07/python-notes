# Python Notes

Python 学习作业与示例代码仓库。

## 目录

| 文件 | 说明 |
|------|------|
| `温度换算.py` | 温度单位换算 —— 支持摄氏度(C)与华氏度(F)互转 |
| `美元 人民币换算.py` | 货币换算 —— 支持美元(USD)与人民币(RMB)互转（汇率 6.78） |
| `爱心.py` | 爱心图案 —— 使用数学方程在终端绘制红色爱心 |

## 使用说明

确保已安装 Python 3，直接运行即可：

```bash
# 温度换算（输入如 36.6C 或 97.8F）
python 温度换算.py

# 美元人民币换算（输入如 USD100 或 RMB678）
python "美元 人民币换算.py"

# 爱心图案
python 爱心.py
```
