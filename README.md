# Python-notes

Python 学习作业与示例代码。

## 文件说明

### 温度换算.py

摄氏度与华氏度互转。程序读取带单位后缀的温度字符串，根据末位字母判断输入单位并换算。

| 输入 | 输出 |
|------|------|
| `36.6C` 或 `36.6c` | 对应的华氏度，如 `97.88F` |
| `97.8F` 或 `97.8f` | 对应的摄氏度，如 `36.56C` |
| 其他格式 | 提示 `输入格式错误` |

换算关系：`F = 1.8 × C + 32`，`C = (F - 32) / 1.8`

### 美元 人民币换算.py

美元与人民币互转，固定汇率 `1 USD = 6.78 RMB`。

| 输入 | 输出 |
|------|------|
| `USD100` | `输入货币RMB678.00` |
| `RMB678` | `输入货币USD100.00` |

> 注意：程序用 `money[3:]` 截取数值，因此前缀必须恰好是 3 个字符（`USD` / `RMB`），写成 `$100` 会取错位置。汇率是写死的，实际使用时需要按当日汇率修改。

### 爱心.py

在终端用字符绘制红色爱心，不使用任何第三方库。

原理是隐函数 `(x² + y² - 1)³ - x²y³ = 0`：逐行逐列判断坐标点是否落在曲线内侧（`<= 0`），落在内部就输出爱心符号，否则输出空格。通过 ANSI 转义序列 `\033[31m` 给字符着色，`\033[0m` 复位。

> 需要终端支持 ANSI 颜色。Windows 10 及以上自带的 Windows Terminal、PowerShell 均支持；老旧的 cmd 窗口可能显示为乱码。

## 运行方式

需要 Python 3，直接运行即可，无需安装依赖：

```bash
python 温度换算.py
python "美元 人民币换算.py"    # 文件名含空格，需加引号
python 爱心.py
```
